# 24h Clock

## Description

Changes supported in-game clock displays to 24-hour format. I only changed the clock displays that are code driven, those that are already in assets are untouched.

## Installation instructions

1. Install [Redscript](https://www.nexusmods.com/cyberpunk2077/mods/1511) and [Cyber Engine Tweaks](https://www.nexusmods.com/cyberpunk2077/mods/107).
2. Install the downloaded ZIP with a mod manager, or manually extract its contents into the game's root folder.

## Main features

- Displays supported clocks in 24-hour format.
- Covers the minimap, HUD and menus, vehicle UI, and supported phone timestamps.

## Requirements

- [Redscript](https://www.nexusmods.com/cyberpunk2077/mods/1511)
