# Cyberpunk2077Mods

A repository containing mods for Cyberpunk 2077:

- **[24h Clock](https://www.nexusmods.com/cyberpunk2077/mods/) ‒** *[source](24h_clock/source)*  
    Displays in-game clocks in 24-hour format.
- **[First-Person Speedometer km/h](speedometer_kmh) ‒** *[source](speedometer_kmh/source)*  
    Displays the first-person vehicle speed in km/h when metric units are selected in the game settings.
