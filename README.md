# Cyberpunk 2077 Mods

A repository containing mods for Cyberpunk 2077:

- **[24h Clock](https://www.nexusmods.com/cyberpunk2077/mods/36406) ‒** *[source](24h_clock)*  
    Displays in-game clocks in 24-hour format.
- **[First-Person Speedometer in km/h](https://www.nexusmods.com/cyberpunk2077/mods/36419) ‒** *[source](speedometer_kmh)*  
    Displays the first-person vehicle speed in km/h when metric units are selected in the game settings.
- **[Self Destruct Vehicle](https://www.nexusmods.com/cyberpunk2077/mods/) ‒** *[source](self_destruct_vehicle)*  
    Detonates the current driving vehicle on a key press.
