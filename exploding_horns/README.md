# Exploding Horns

## Description

Makes vehicles explode when their horns are activated. Mod Settings controls
let you choose whether the player's vehicle, other vehicles, or both are
affected.

## Installation instructions

1. Install [Redscript](https://www.nexusmods.com/cyberpunk2077/mods/1511).
2. Optional: Install [Mod Settings](https://www.nexusmods.com/cyberpunk2077/mods/4885) to configure vehicle scope in the in-game Mod Settings menu.
3. Install the mod with a mod manager, or manually extract its contents into the game's root folder.

## Requirements

- [Redscript](https://www.nexusmods.com/cyberpunk2077/mods/1511)

Mod Settings is optional. Without it, both vehicle options default to enabled.
