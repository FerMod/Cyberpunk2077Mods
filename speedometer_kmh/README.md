# First-Person Speedometer km/h

## Description

Displays first-person vehicle speed in km/h when metric units are selected.

## Installation instructions

1. Install [Redscript](https://www.nexusmods.com/cyberpunk2077/mods/1511).
2. Install the downloaded ZIP with a mod manager, or manually extract its contents into the game's root folder.
3. In the game settings, set **Interface > Speedometer Units** to metric.

## Main features

- Displays first-person vehicle speed in km/h with metric units selected.
- Retains mph when the game is set to imperial units.

## Requirements
